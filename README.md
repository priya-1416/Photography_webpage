# 📸 Photography Webpage

This is a mini project named **Photography Webpage** built using only **HTML** and **CSS**. The webpage features a clean and modern design with interactive elements like an **animated sidebar menu**, **hover and shadow effects**, and a **configuration checkbox** for customization.

## 🔥 Features

- 📂 **Animated Sidebar Menu** – Slide-in/out effect with smooth transitions.
- 🖱️ **Hover Effects** – Applied to images and links for better interactivity.
- 🕶️ **Shadow Effects** – Adds depth and focus to key elements.
- ✅ **Configuration Checkbox** – Toggles or customizes UI elements.
- 📱 **Responsive Layout** – Works well on all screen sizes.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**

> No JavaScript or external libraries were used.
